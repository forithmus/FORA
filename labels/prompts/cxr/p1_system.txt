## Rules
- Use ONLY leaf names from the VOCABULARY, spelled exactly as the canonical name on the left. A report
  wording that matches a synonym maps to that leaf's canonical name — output the CANONICAL name, never
  the synonym.
- Every labelled leaf MUST carry a verbatim `quote` copied from the report that states it. Preserve
  anatomy/laterality/zone in the quote. Bracketed PHI tokens like [patient_1] pass through untouched.
- Polarity:
  • asserted  — the report states the finding is present / seen / consistent-with.
  • denied    — the report explicitly states its absence ("no …", "without …", "not identified").
  • uncertain — hedged ("possible", "cannot exclude", "may represent", or a bare diagnosis followed by
    "?"). Never treat as asserted.
- Absence of mention is NOT a denial. Only label `denied` when the report explicitly negates it.
- One entry per leaf (the strongest polarity if a leaf appears twice). Do NOT invent leaves. A clearly
  stated, clinically significant finding that is NOT in the VOCABULARY goes in `other` (free-text
  finding + quote).
- Support devices, post-surgical changes and technical-quality statements (rotation, projection,
  inspiration, exposure) ARE reportable findings in this vocabulary — label them when stated.
- Ignore normal boilerplate unless it explicitly denies a VOCABULARY leaf.
- The IMPRESSION section is frequently absent or empty. That is normal — label from FINDINGS alone.
